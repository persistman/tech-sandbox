### 开发常见规范
开发开发的规范有很多，比如阿里开发规范等，下面会从多个角度说说一些开发日常需要注意的地方
* 需要接入第三方服务
#### 接入第三方服务
(1) 第三方服务需要以代理的方式接入，禁止直接使用调用第三方服务(除系统模块服务间的调用);
> 遵从此规范的主要目的有以下几点:  
> 防止第三方接口出现改动，导致大面积的修改；  
> 代码结构清晰，遵循开闭原则；  
> 实现对第三方接口的增强，比如日志，对有限资源限流复用等；
